### <a name="_qmphm5d6rvi3"></a>**Решение**

[Диаграмма контекста](Context.puml)  
[Диаграмма контейнеров](Container.puml)

Будет выделен отдельный сервис на Java Spring Boot, который будем заниматься выгрузкой ставок партнеру.
Выбрана Java, потому что у команды АБС есть экспертиза в этом языке.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- Делиться доступом к БД напрямую для партнера. 
Отказались по соображениям безопасности.

- Выставить ручку для получения ставок в партнерском КЦ.
Но необходима была бы работа на стороне партнера, чтобы поддержать эти изменения.

- Использовать email почту как канал связи для отправки. 
Причины отказа – ручная работа, зависимость от сервиса рассылок
