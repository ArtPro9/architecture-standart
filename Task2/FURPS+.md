| Код | Требования                                                                                                                         | Комментарий |
|-----|------------------------------------------------------------------------------------------------------------------------------------|-------------|
| F   | Функциональные требования (Functionality)                                                                                          |             |
| F1  | Клиент оставляет на сайте свои полные контактные данные (ФИО, телефон) для последующего взаимодействия с менеджером.               |             |
| F2  | Пользователи могут инициировать заявки на открытие депозитов как через веб-сайт, так и посредством интернет-банка.                 |             |
| F3  | В интернет-банке клиенту предоставляется персонализированный перечень депозитных продуктов с актуальными ставками.                 |             |
| F4  | При подаче заявки в интернет-банке пользователь указывает номер счёта и желаемую сумму депозита.                                   |             |
| F5  | Подтверждение заявки в интернет-банке осуществляется посредством ввода одноразового СМС-кода.                                      |             |
| F6  | Менеджер в системе кол-центра анализирует поступившие заявки и формирует индивидуальные предложения.                               |             |
| F7  | Для завершения оформления клиент обязан лично посетить отделение банка и пройти процедуру подтверждения личности.                  |             |
| F8  | На веб-сайте отображается актуальный каталог депозитных продуктов с текущими ставками.                                             |             |
| F9  | Система должна обеспечивать импорт и экспорт данных по ставкам депозитов в формате XLS для удобства управления.                    |             |
| F10 | Необходимо реализовать интеграцию между бэк-офисом депозитов, кредитным бэк-офисом и автоматизированной банковской системой (АБС). |             |
| F11 | Менеджер бэк-офиса обрабатывает заявки и подтверждает условия депозита напрямую в АБС.                                             |             |
| F12 | После успешного открытия депозита клиенту автоматически отправляются СМС-уведомления с подтверждением.                             |             |
| U   | Удобство использования (Usability)                                                                                                 |             |
| U1  | Интерфейсы пользователей должны строго соответствовать корпоративным стандартам дизайна и удобства.                                |             |
| U2  | Все пользовательские операции должны выполняться с минимальной задержкой — отклик системы в пределах миллисекунд.                  |             |
| R   | Надёжность (Reliability)                                                                                                           |             |
| R1  | Все передаваемые данные должны быть защищены с помощью современных методов шифрования для обеспечения конфиденциальности.          |             |
| R2  | Система должна обеспечивать непрерывную работу с доступностью не менее 99,9% времени.                                              |             |
| R3  | Сервисы интернет-банка обязаны сохранять работоспособность и устойчивость при сбоях в центре обработки данных (ЦОД).               |             |
| P   | Производительность (Performance)                                                                                                   |             |
| P1  | Масштабирование системы должно происходить эффективно, не создавая чрезмерной нагрузки на базу данных АБС.                         |             |
| P2  | Архитектура системы должна поддерживать равномерное горизонтальное масштабирование для обеспечения стабильной работы.              |             |
| P3  | Время загрузки справочной информации должно быть минимальным — не превышать одной секунды.                                         |             |
| S   | Поддерживаемость (Supportability)                                                                                                  |             |
| S1  | Использование проверенных технологий (MS SQL, Oracle) позволит сократить сроки обучения и внедрения.                               |             |
| S2  | Архитектура и кодовая база системы должны обеспечивать простоту внесения изменений и расширения функционала.                       |             |
| S3  | Вся техническая и пользовательская документация должна быть подготовлена для облегчения дальнейшего сопровождения и развития.      |             |
| +R  | Ограничения (Restrictions)                                                                                                         |             |
| +R1 | На текущий момент платформа интернет-банка не поддерживает интеграцию с системой Kafka.                                            |             |
| +R2 | Масштабирование базы данных АБС возможно исключительно вертикальным способом.                                                      |             |
| +R3 | Из-за ограничений производительности прямое взаимодействие интернет-банка с API АБС запрещено.                                     |             |
